# Level 1 — 中検1級 1年学習ガイド

2027年11月の中国語検定1級合格を目指して、**毎日どの教材の何ページ／何問目をやるか**を示すアプリです。
`index.html` をダブルクリックすれば開けます。サーバーもビルドも要りません。GitHub Pages でそのまま公開でき、iPhone ではホーム画面に追加して使えます。

## 画面
| タブ | 内容 |
|---|---|
| Today | 試験までの残り日数、全体の進捗、その日のタスク（教材・範囲・目安時間）。チェックすると印が付く |
| Plan | 週ごとの予定と、1年分のカレンダー（学習した日ほど濃く塗られる） |
| Idioms | 成語・俗語・惯用语・歇后语ドリル（約390項目、間隔反復） |
| Translate | 中文日訳・日文中訳の演習 50題（自分の訳を保存できる。模範訳とポイントつき） |
| Progress | 教材ごとの達成数と、予定ペース（縦線） |
| ⚙ Settings | 開始日・試験日・休みの曜日・ジャーナルの時間・過去問の回数・『誤用』基礎編のページ・テーマ・データの書き出しと読み込み |

予定より遅れたら、Today の `overdue · Rebalance`（または Settings の `Rebalance from today`）を押します。
残りの範囲が、今日以降の日に割り直されます。

## スケジュール（初期値: 2026-10-06 → 2027-11-28、1日約3時間）
| 期間 | 中心にやること |
|---|---|
| P1 Foundation（10月〜1月） | 誤用から学ぶ中国語 3冊（全200項目）、合格奪取 準1級 STEP1–2、キクタン上級 Day1–98、土曜は翻訳 |
| P2 Pre-1 Format（2月〜5月） | 合格奪取 準1級 STEP3–4・模試、1級 STEP1–2、HSK 7–9 語彙、成語ドリル、水・土は翻訳 |
| P3 Level 1 Format（6月〜9月） | 合格奪取 1級 STEP3–4・模試、過去問1巡目（土=筆記、日=リスニング＋復習）、誤用とキクタンの復習 |
| P4 Final（10月〜試験） | 過去問2巡目（時間を計る）、過去問の間違い直し、翻訳のやり直し、成語の総復習 |

毎日入るもの: 中国語ジャーナル（リスニング、時間だけを指定）。P2 以降は長文読解 30分も入ります。

## 教材データ
- `data/books.js` — 各教材の章立てとページ。『誤用』続編1・続編2 は目次のページ番号どおり。
  『誤用』基礎編の項目別ページと『合格奪取』のページは公開情報がないため、基礎編は推定ページ（`p.≈`）、合格奪取は問題番号で示します。
  基礎編の実際のページは Settings に100項目分の開始ページを入れると反映されます。
- `data/idioms-*.js`、`data/translation-*.js` — このアプリ用に書き下ろした成語ドリルと翻訳課題です。

## 検証
```bash
node tools/check-plan.js   # 全教材の全範囲が試験日前に1回ずつ割り当てられているかを確認
```

進捗はブラウザの localStorage に保存されます。端末を替えるときは Settings の Export / Import を使ってください。
