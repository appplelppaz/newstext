# Level 1 — 中検1級 1年学習ガイド

2027年11月の中国語検定1級合格を目指して、**毎日どの教材の何ページ／何問目をやるか**を示すアプリです。
`index.html` をダブルクリックすれば開けます。サーバーもビルドも要りません。GitHub Pages でそのまま公開でき、iPhone ではホーム画面に追加して使えます。

## 画面
| タブ | 内容 |
|---|---|
| Today | 試験までの残り日数と、その日のタスク（教材・目次の項目名・ページ・目安時間）。合計が毎日の学習時間（初期値3時間）に収まるように組んである。弱点から決まる重点課題（Focus・Writing focus）もここに入る |
| Plan | 週ごとの予定（教材と最初の項目名）、1年分のカレンダー、**Books**（本ごとの目次と、どの項目を何日にやるか。目次の貼り付けもここ） |
| Papers | 過去問（1級3回・準1級10回）。4択の自動採点と解説、書き取りの自動採点、要約・翻訳の Claude 添削、Mistakes（間違えた問題の間隔反復）、Exam guide、Method |
| Words | 成語・俗語ドリル（約390項目）、過去問の語彙カード（Vocab）、手で書けなかった字の復習（Hanzi）、紛らわしい語のグループ（Groups） |
| Listen | 本物の声の聞き取り。PodcastPlayer 用の JSON と音声を取り込み、通し聞き・1文ずつの書き取り（自動照合）・シャドーイング・要約（1級のリスニング2の形式、Claude で添削）を行う |
| Translate | 日文中訳ドリル（本物の記事から出題し、Claude が添削）と、中文日訳・日文中訳の演習 50題（書き下ろし） |
| Progress | 最上部に **Weak points**（チェックポイントの分野・過去問の大問・問題の種類・Claude の添削の分類・書き取りの正答率を弱い順に）。教材ごとの達成数、チェックポイントの推移、過去問の得点、Writing、日文中訳ドリル、Listening |
| ⚙ Settings | 開始日・試験日・休みの曜日・**1日の学習時間**・聞き取りの時間・インプット期間の延長日数・テーマ・データの書き出しと読み込み |

予定より遅れたら、Today の `overdue · Rebalance` を押すと、残りの範囲が今日以降の日に割り直されます。

## iPad Pro 13インチ ＋ Apple Pencil
iPad Pro 13インチで使う前提で作っています。Safari で開き、共有メニューの「ホーム画面に追加」を選ぶと全画面で使えます。

- **画面の構成**：左にサイドバーがあります。横向きでは名前つき、縦向きではアイコンだけになります。
  - 過去問は左右に分けて表示します。左は本文・音声・メモ、右は設問・解説です。読解では、いま解いている設問の空欄を本文中で強調し、その位置まで自動でスクロールします。
  - Magic Keyboard を使うときは、1〜4キーで選択肢を選び、Enter で次へ進みます。
- **文字を書く所はすべてスクリブル**：入力欄に Pencil で書くと、iPadOS のスクリブルが文字にします（キーボードでも打てます）。画像は送らず、文字になったものを採点に使います。
  - 準備：設定 › Apple Pencil › スクリブル をオンにし、設定 › 一般 › キーボード › キーボード に「中国語（簡体字）」を追加します。
  - スクリブルは崩れた字を正しい字に直して読み取ることがあるので、字形の採点は甘くなります。止め・はね・画数は、ときどき紙に書いて確かめてください。
- **アプリがその場で採点する所**（答えが一つに決まる問題）
  - 書き取り：Check を押すと1字ずつ差分を出し、誤り・抜け・余分1字ごとに2点引いた目安を Score 欄に入れます（直せます）。書けなかった字は Hanzi デッキに入ります。
  - ピンインの漢字書き・Words › Hanzi・チェックポイントの Writing：解答と一致すれば ✓、違えば ✗ と正しい字を表示し、間違えた字は Hanzi デッキに入ります。
- **Claude で添削する所**（作文・日文中訳・中文日訳・要約・Translate タブ）
  - 字数・指定語・繁体字の混用は、書いている間に自動でチェックします。
  - Check の後に「Claude で添削」を押すと、iPad の共有シートが開きます。Claude アプリを選ぶと、原文・解答例・採点の観点・自分の答えを含む依頼文が送られます。共有シートに出ないときは「Copy」を押し、Claude アプリに貼り付けて送ってください。
  - Claude が返すもの：総評、誤りの一覧（該当箇所 → 正しい形 → 理由、分類タグつき）、よかった点、弱点の診断、次の練習、覚える表現、直した全文。最後に `=== RESULT ===` ブロック（`SCORE` 点数・`TAGS` 誤りの分類と件数・`WEAK` 一番の弱点・`WORDS` 覚える表現）が付きます。
  - 返答をコピーして「Paste result」を押すと読み込みます。点数は大問の Score 欄に入り、誤りの分類は Progress の **Writing** 欄に集計され、覚える表現は Hanzi デッキに入ります。次にその問題を開くと、前回の添削が表示されます。
  - 誤りの分類は12種（語義・コロケーション・文法・語順・虚詞と補語・和製漢語・訳し落とし・文体・誤字・構成・要点の欠落・字数）。直近14日で同じ分類が3回以上出ると、平日の Today に「Writing focus」（その弱点に合った練習とアプリ内の行き先）が入ります。
- 聞き取りのメモ帳だけは、採点に使わないので Pencil の手書きのままです。一度 Pencil で書くと、以後は指で触れても線を引かず、画面のスクロールになります。書いた線は iPad の中（IndexedDB）に保存されます。
- **Apple Pencil を使わない所**：4択・ピンイン・成語の意味（タップで速く量をこなす）。本文へのマーカーは学習効果が低いので用意していません。根拠は Method 画面にまとめています。

## 日文中訳ドリル（Translate › 日文中訳ドリル）
本物の中国語の記事から出題し、Claude に1級の採点基準で添削してもらう練習です。10月から、火・金の Today に入ります（P1 は150字前後、2月から150〜250字）。

1. **原文を選ぶ**：人民網・光明網・新華網などの記事を貼り付ける（原文ストックに貯めておける）。手元に記事がないときは「Claude が作成」で原文から作ってもらう
2. **出題**：「Claude で出題」で依頼文を Claude アプリに送り、返ってきた返答を「Paste result」で読み込む。自然な日本語の問題文と、文ごとの原文の対応・採点ポイントが入る
3. **訳す**：スクリブルで中国語に訳す。ヒントは1回につき −2点。迷った所は「追加の質問」に書く
4. **添削**：「提出して添削」で、文ごとの【誤り】【改善】【別解OK】、模範訳、減点、覚えるべき表現、良かった点・次の課題と、最後に記録用の JSON が返る。返答を貼ると、100点満点の得点（合格目安80点）・文ごとの朱筆・弱点が表示される

- **表現ノート**：覚えるべき表現を保存し、日本語 → 中国語で言えるか自己テストする。未習得の表現は次の出題で優先して使われる。✎ Hanzi で手書きの復習にも回せる
- **記録**：得点の推移、よく出る弱点（例：同形異義語・量詞・結果補語）、これまでの添削。過去の弱点の上位6件は、次の添削の依頼文に入り、同じ誤りのくり返しが指摘される
- 誤りの分類は Progress の Writing にも集計され、Today の Writing focus につながる
- 原文ストックと記録は iPad の中（IndexedDB）に保存されます（Settings の Export にも入ります）

## Listen（本物の声で聞く）
聞き取りの練習は、合成音声ではなく実際の人の声で行います。毎日の Today には、**Journal**（中国語ジャーナル：通し聞き → スクリプト → 聞き直し → シャドーイング）と **Podcast**（Listen での練習）が入ります。

1. Cowork の podcast-json / ttml-to-json で、Apple Podcasts の中国語の番組から JSON（原文・時刻・ピンイン・和訳・語彙）を作る
2. iPad の「ファイル」で Google Drive › Podcasts › 中国語 を開けるようにしておく（Google Drive アプリ）
3. Listen › Import で、同じ名前の `.json` と `.mp3`（または `.m4a`）をまとめて選ぶ

| モード | やること |
|---|---|
| Listen | 約90秒ずつ、原稿を見ずに聞く → 原稿を開いて確かめる。文を押すとその文だけ鳴る |
| Dictation | 1文ずつ聞いてスクリブルで書き、原稿と1字ずつ照合する。聞き取れなかった字は Hanzi デッキへ |
| Shadow | 原稿を見て3回、隠して2回、音声に重ねて言う |
| Summary | 1.5〜2分を3回まで聞き、メモを取り、180〜200字に要約する。Claude で添削し、結果は Progress の Writing に入る |

- 中検は簡体字・普通話なので、大陸の番組を選んでください。繁体字の番組には注意が出ます（書き取りでは繁体字と簡体字の違いを誤りに数えません）。
- 自動の文字起こしには誤りもあります。原稿が変だと思ったら、耳を信じてください。
- 音声は iPad の中（IndexedDB）に保存されます。1時間の番組でおよそ 50〜60 MB です。要らなくなった番組は Delete で消せます。

## オフラインで使う
一度ネットにつないで開くと、アプリのファイルと字体が iPad の中に保存され、以後は電波がなくても開けます（Service Worker：`sw.js`）。

1. Safari でアプリを開く（ネットにつないだ状態で）
2. 共有ボタン › 「ホーム画面に追加」を選ぶ（全画面で使え、保存したデータも消されにくくなる）
3. 過去問の JSON とポッドキャストの JSON・音声は、一度 Import すれば端末に残る（音声も電波なしで聞ける）

過去問とチェックポイントの聞き取りだけは公式の音声がないので、原稿を iPad の読み上げで鳴らします（読み上げの声は 設定 › アクセシビリティ › 読み上げコンテンツ › 声 › 中国語 で用意できます）。

保存の状態は Settings の **Offline** 欄で確かめられます。アプリを更新したときは、次に開いたときに「Updated · tap to reload」が出るので、押すと新しい版になります。
`sw.js` の `PRECACHE` にはアプリのファイルを列挙しています。ファイルを足したら一覧に入れ、`VERSION` を上げてください（`node tools/check-offline.js` で入れ忘れを確認できます）。

## スケジュール（初期値: 2026-10-06 → 2027-11-28、毎日3時間）
インプットを先に十分行い、そのあとで翻訳などのアウトプットに移る構成です。

- **1日の時間**：Settings の「Study · min / day」（初期値180分）。
  - 固定のタスクを先に置きます：聞き取り40分、多読20分、Mistakes、ドリル、語彙カード、過去問など。
  - 残りの時間を、その日に進める教材で分け合います。
  - 範囲は時間に比例して割り振るので、どの日も合計がほぼ同じになります。
  - 大きな単位が置けずに時間が余った日は「**Catch-up**」（遅れの取り戻しか、Weak points の復習）が入ります。
  - P4 では、余った時間で過去問の弱い大問をやり直します（「**Weak sections**」）。
- **教材の進め方**：誤用3冊・キクタン・合格奪取 STEP1–2 は P1 で、合格奪取の残りは P2 で終えます。HSK 7–9 と成語は P2〜P3 です。

| 期間 | 中心にやること |
|---|---|
| P1 Input（10/6〜1/31） | 誤用から学ぶ中国語 3冊、合格奪取 STEP1–2、キクタン上級 Day1–98、多読、日文中訳ドリル（火・金）。10/10 に準1級 #117 で診断、1/23 に #108 |
| P2 Input → Output（2/1〜4/30） | 合格奪取の残りと模試、HSK 7–9、成語ドリル、翻訳演習を週2回、準1級 #109–#112 |
| P3 Output · Papers（5/1〜8/31） | 準1級 #113–#116、1級 #110、誤用とキクタンの復習、翻訳演習 |
| P4 Final（9/1〜試験前日） | 1級 #113・#110・#116（#116 は 10/16 に本番形式の模試）と2巡目、翻訳演習のやり直し、弱い大問のやり直し、成語の総復習 |

**毎日入るもの**
- Journal（中国語ジャーナル）と Podcast（Listen）
- Reading
- Mistakes（平日）
- 日文中訳ドリル（火・金）
- Exam Vocab（P2 から）

過去問は、土曜に筆記（120分）、日曜にリスニングと復習（90分）です。日曜の Review では、Progress の Weak points を見て、来週どこに時間を回すかを決めます。

## チェックポイント（CP0〜CP6）
約6〜8週ごとに40分の小テスト（文法・多音字・成語・聞き取り・過去問の語彙・成語の書き取り）を行います。
分野別の正答率を目標値と比べ、弱い分野を次のチェックポイントまで平日の Today に重点課題として入れます。
CP2 の合計が70%未満なら、インプット期間を2週間延ばすボタンが出ます（翻訳演習と P2 の開始が遅れます。日文中訳ドリルは続けます）。

## 過去問データ（リポジトリには入れていません）
過去問の問題文・解答は日本中国語検定協会の著作物で、PDF に「無断で複製・複写・転載することを禁じます」とあります。
そのため、このリポジトリには回の一覧（回番号・Drive のファイル ID・配点）だけを置いています（`data/papers-index.js`）。

本文と解説は回ごとの JSON ファイル（`paper-L1-116.json` など）を Google Drive に置き、Papers › Import で読み込みます（複数のファイルをまとめて選べます）。
読み込んだデータはブラウザの IndexedDB に保存されます。`.gitignore` で `*paper*.json` を除外しています。

JSON に含まれる解説はすべて書き下ろしです。
- 4択は全選択肢について、意味と、なぜ正解か／なぜ誤りかを説明します。語の成り立ち、コロケーション、和製漢語の罠も扱います。
- 長文とリスニング原稿には、全文の和訳と重要語のリストを付けています。
- 翻訳は文ごとに訳し方を説明し、別の訳し方と減点されやすい点も示します。
- 要約には、要点の押さえ方と組み立て方を付けています。

## 教材データ
- `data/books.js` — 各教材の目次（章・項目名・ページ）。『誤用』は基礎編・続編1・続編2 とも目次のとおりです。
  - 合格奪取（STEP 内の見出し）とキクタン（週の見出し）は、目次が手に入りしだい `sections` / `weeks` に入れます。
  - アプリの Plan › Books で目次を貼り付けて直すこともでき、その場合は設定に保存されて `books.js` より優先されます。
- `data/idioms-*.js`、`data/translation-*.js`、`data/checkpoints.js`、`data/guide.js` — このアプリ用に書き下ろした問題・解説・学習法ガイド（参考文献つき）です。

## 検証
```bash
node tools/check-offline.js   # sw.js のキャッシュ一覧にアプリの全ファイルが入っているかを確認
node tools/check-plan.js   # 全範囲が試験日前に1回ずつ割り当てられているか、120分のタスクが重ならないかを確認
```

進捗はブラウザに保存されます。端末を替えるときは Settings の Export / Import を使ってください。
