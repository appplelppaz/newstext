# NEWSTEXT — 週刊 多言語ニュースマガジン

イギリス・中国・スペイン・フランスの **その週の話題** を教材に、4言語を楽しみながら学ぶ
週刊のウェブマガジンです。ENGLISH JOURNAL のような誌面を目指し、
**日本語訳・語注・文法解説を原文のすぐ横に常時表示**します。

## 開き方

`index.html` を**ダブルクリックするだけ**で読めます。サーバーもビルドも不要です
（記事データは `data/magazine.js` に埋め込んであります）。

ローカルサーバーで開きたい場合:

```bash
python3 -m http.server 8000    # → http://localhost:8000/
```

GitHub Pages にそのまま公開することもできます（リポジトリ直下が誌面です）。

## 誌面のつくり

**表紙 → 目次 → 記事** の3画面。毎号、4か国それぞれに次の7コーナーが載ります。

| コーナー | 内容 |
|---|---|
| カバーストーリー | その週その国で一番話題の出来事 |
| 今週の短信 | ニュース短信3本 |
| 街の会話 | 今週の話題を現地の友人同士が話す日常会話 |
| 暮らしのコラム | 生活・習慣・世相のエッセイ |
| 今週のことば | 流行語・時事キーワード5語 |
| 今週の文法 | その週の記事に出た文法を1点、例文と対比つきで掘り下げる |
| カルチャー案内 | 料理・音楽・映画・行事など |

ニュースだけに偏らないよう、7コーナーのうち4つを日常・文化側に置いています。
文法コーナーは、その号の記事に**実際に出てきた**文法を扱うので、
「さっき読んだあの文はこういう仕組みだった」とつながります。

### 学習のしかけ

- **3層レイアウト** — 原文・日本語訳・欄外の語注／文法解説が同時に見えます
- **語彙ハイライト** — 語注のある語は原文中でマーカー表示。クリックすると
  語義がその場にポップアップし、欄外の該当項目も光ります
- **ピンインのルビ** — 中国語は漢字の上にピンイン。表示/非表示を切り替えられます
- **記事末の語彙まとめ** — その記事に出た語を一覧で復習できます
- レベル（初級/中級/上級）と種別で目次を絞り込めます

## 号について

号は ISO 週番号で管理します（`2026-W36` = 2026年9月 第1週号、8/31〜9/6）。
記事の `publishDate` がその週から外れているとビルドが通らないので、
「先週のネタが混ざる」ことは起こりません。

## 新しい号を作る

Claude Code で **「今週号を作って」** と頼めば、`.claude/skills/weekly-issue/`
の手順に従って RSS の取得から執筆・ビルド・コミットまで進みます。
1回の実行で1言語（7コーナー）ぶん。残りは「続けて」で継続します。

手作業で回す場合は次の順です。

```bash
python3 tools/fetch_feeds.py     # その週の記事を各社 RSS から取得 → data/raw/
#   … data/raw/ を読んで記事 JSON を data/articles/<lang>/ に書く …
python3 tools/add_pinyin.py      # 中国語にルビ・語注・例文のピンインを付ける
python3 tools/build.py           # 検証して data/magazine.js を生成
```

## 構成

```
index.html                  誌面本体
assets/{style.css,app.js}   誌面スタイルと描画（依存ライブラリなし）
data/
  magazine.js               ★ビルド生成。window.NEWSTEXT に全号を格納
  issues/<issue>/issue.json 号の扉（特集コピー・今週の4か国）
  articles/<lang>/*.json    ★記事の正データ
  raw/<lang>-<issue>.json   RSS 取得ログ（題材選定の材料）
tools/
  feeds.py                  購読フィード一覧
  weekutil.py               号ID ↔ 週の範囲・誌面表記
  fetch_feeds.py            RSS 取得（週フィルタ付き）
  authoring.py              記事を書くための補助
  add_pinyin.py             中国語のピンイン付与
  build.py                  検証とバンドル
```

記事のスキーマは既存の podcast-json スキル（`segments` / `words` / `grammar`）を
踏襲しています。語注には見出し語 `word` とは別に、原文中の実際の表記 `surface` を
持たせてあり、活用する言語でもハイライトが正しく当たります。

## 素材の扱いについて

- **カバーストーリー・今週の短信** — 各社が配信目的で公開している **RSS の見出しと要約**
  のみを、出典名と元記事リンクを明示して引用しています。著作権は各報道機関に帰属します。
  記事本文をスクレイピングして収録することはしません。
- **街の会話・暮らしのコラム・今週のことば・今週の文法・カルチャー案内** — 同じ話題をもとにした
  本誌の書き下ろしです。会話の話者は架空の人物です。
