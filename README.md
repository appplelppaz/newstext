# Level 1 — 中検1級 1年学習ガイド

2027年11月の中国語検定1級合格を目指して、**毎日どの教材の何ページ／何問目をやるか**を示すアプリです。
`index.html` をダブルクリックすれば開けます。サーバーもビルドも要りません。GitHub Pages でそのまま公開でき、iPhone ではホーム画面に追加して使えます。

## 画面
| タブ | 内容 |
|---|---|
| Today | 試験までの残り日数と、その日のタスク（教材・範囲・目安時間）。チェックすると印が付く。チェックポイントの結果から決まる重点課題もここに入る |
| Plan | 週ごとの予定と、1年分のカレンダー |
| Papers | 過去問（1級3回・準1級10回）。4択の自動採点と解説、書き取り・要約・翻訳の自己採点、Mistakes（間違えた問題の間隔反復）、Exam guide、Method |
| Words | 成語・俗語ドリル（約390項目）、過去問の語彙カード（Vocab）、手で書けなかった字の復習（Hanzi）、紛らわしい語のグループ（Groups） |
| Translate | 中文日訳・日文中訳の演習 50題（書き下ろし） |
| Progress | 教材ごとの達成数、チェックポイントの推移、過去問の得点、問題の種類別・間違いの原因別の正答率、Claude の添削で見つかった弱点（Writing） |
| ⚙ Settings | 開始日・試験日・休みの曜日・ジャーナルの時間・インプット期間の延長日数・テーマ・データの書き出しと読み込み |

予定より遅れたら、Today の `overdue · Rebalance` を押すと、残りの範囲が今日以降の日に割り直されます。

## iPad Pro 13インチ ＋ Apple Pencil
iPad Pro 13インチで使う前提で作っています。Safari で開き、共有メニューの「ホーム画面に追加」を選ぶと全画面で使えます。

- **画面の構成**：左にサイドバーがあります。横向きでは名前つき、縦向きではアイコンだけになります。
  - 過去問は左右に分けて表示します。左は本文・音声・メモ、右は設問・解説です。読解では、いま解いている設問の空欄を本文中で強調し、その位置まで自動でスクロールします。
  - Magic Keyboard を使うときは、1〜4キーで選択肢を選び、Enter で次へ進みます。
- **文字を書く所はすべてスクリブル**：入力欄に Pencil で書くと、iPadOS のスクリブルが文字にします（キーボードでも打てます）。画像は送らず、文字になったものを採点に使います。
  - 準備：設定 › Apple Pencil › スクリブル をオンにし、設定 › 一般 › キーボード › キーボード に「中国語（簡体字）」を追加します。
  - スクリブルは崩れた字を正しい字に直して読み取ることがあるので、字形の採点は甘くなります。止め・はね・画数は、ときどき紙に書いて確かめてください。
- **アプリがその場で採点する所**（答えが一つに決まる問題）
  - 書き取り：Check を押すと1字ずつ差分を出し、誤り・抜け・余分1字ごとに2点引いた目安を Score 欄に入れます（直せます）。書けなかった字は Hanzi デッキに入ります。
  - ピンインの漢字書き・Words › Hanzi・チェックポイントの Writing：解答と一致すれば ✓、違えば ✗ と正しい字を表示し、間違えた字は Hanzi デッキに入ります。
- **Claude で添削する所**（作文・日文中訳・中文日訳・要約・Translate タブ）
  - 字数・指定語・繁体字の混用は、書いている間に自動でチェックします。
  - Check の後に「Claude で添削」を押すと、iPad の共有シートが開きます。Claude アプリを選ぶと、原文・解答例・採点の観点・自分の答えを含む依頼文が送られます。共有シートに出ないときは「Copy」を押し、Claude アプリに貼り付けて送ってください。
  - Claude が返すもの：総評、誤りの一覧（該当箇所 → 正しい形 → 理由、分類タグつき）、よかった点、弱点の診断、次の練習、覚える表現、直した全文。最後に `=== RESULT ===` ブロック（`SCORE` 点数・`TAGS` 誤りの分類と件数・`WEAK` 一番の弱点・`WORDS` 覚える表現）が付きます。
  - 返答をコピーして「Paste result」を押すと読み込みます。点数は大問の Score 欄に入り、誤りの分類は Progress の **Writing** 欄に集計され、覚える表現は Hanzi デッキに入ります。次にその問題を開くと、前回の添削が表示されます。
  - 誤りの分類は12種（語義・コロケーション・文法・語順・虚詞と補語・和製漢語・訳し落とし・文体・誤字・構成・要点の欠落・字数）。直近14日で同じ分類が3回以上出ると、平日の Today に「Writing focus」（その弱点に合った練習とアプリ内の行き先）が入ります。
- 聞き取りのメモ帳だけは、採点に使わないので Pencil の手書きのままです。一度 Pencil で書くと、以後は指で触れても線を引かず、画面のスクロールになります。書いた線は iPad の中（IndexedDB）に保存されます。
- **Apple Pencil を使わない所**：4択・ピンイン・成語の意味（タップで速く量をこなす）。本文へのマーカーは学習効果が低いので用意していません。根拠は Method 画面にまとめています。

## オフラインで使う
一度ネットにつないで開くと、アプリのファイルと字体が iPad の中に保存され、以後は電波がなくても開けます（Service Worker：`sw.js`）。

1. Safari でアプリを開く（ネットにつないだ状態で）
2. 共有ボタン › 「ホーム画面に追加」を選ぶ（全画面で使え、保存したデータも消されにくくなる）
3. 聞き取り練習のために、iPad の 設定 › アクセシビリティ › 読み上げコンテンツ › 声 › 中国語 で、高音質の声をダウンロードしておく
4. 過去問の JSON は一度 Import すれば端末に残る

保存の状態は Settings の **Offline** 欄で確かめられます。アプリを更新したときは、次に開いたときに「Updated · tap to reload」が出るので、押すと新しい版になります。
`sw.js` の `PRECACHE` にはアプリのファイルを列挙しています。ファイルを足したら一覧に入れ、`VERSION` を上げてください（`node tools/check-offline.js` で入れ忘れを確認できます）。

## スケジュール（初期値: 2026-10-06 → 2027-11-28、1日3時間以上）
インプットを先に十分行い、そのあとで翻訳などのアウトプットに移る構成です。教材は3月末までに終えます。

| 期間 | 中心にやること |
|---|---|
| P1 Input（10/6〜12/31） | 誤用から学ぶ中国語 3冊、合格奪取 STEP1–2、キクタン上級 Day1–98、多読。10/10 に準1級 #117 で診断、12/19 に #108 |
| P2 Input → Output（1/1〜3/31） | 合格奪取の残りと模試、HSK 7–9 語彙、成語ドリル、翻訳を週2回、準1級 #109–#112 |
| P3 Output · Papers（4/1〜8/31） | 準1級 #113–#116、1級 #110、復習、翻訳 |
| P4 Final（9/1〜試験前日） | 1級 #113・#116（#116 は 10/16 に本番形式の模試）と2巡目、間違い直し、成語の総復習 |

毎日入るもの: 中国語ジャーナル（リスニング）。過去問は土曜に筆記（120分）、日曜にリスニングと復習です。

## チェックポイント（CP0〜CP6）
約6〜8週ごとに40分の小テスト（文法・多音字・成語・聞き取り・過去問の語彙）を行います。
分野別の正答率を目標値と比べ、弱い分野を次のチェックポイントまで平日の Today に重点課題として入れます。
CP2 の合計が70%未満なら、インプット期間を2週間延ばすボタンが出ます。

## 過去問データ（リポジトリには入れていません）
過去問の問題文・解答は日本中国語検定協会の著作物で、PDF に「無断で複製・複写・転載することを禁じます」とあります。
そのため、このリポジトリには回の一覧（回番号・Drive のファイル ID・配点）だけを置いています（`data/papers-index.js`）。

本文と解説は回ごとの JSON ファイル（`paper-L1-116.json` など）を Google Drive に置き、Papers › Import で読み込みます（複数のファイルをまとめて選べます）。
読み込んだデータはブラウザの IndexedDB に保存されます。`.gitignore` で `*paper*.json` を除外しています。

JSON に含まれる解説はすべて書き下ろしです。
- 4択は全選択肢について、意味と、なぜ正解か／なぜ誤りかを説明します。語の成り立ち、コロケーション、和製漢語の罠も扱います。
- 長文とリスニング原稿には、全文の和訳と重要語のリストを付けています。
- 翻訳は文ごとに訳し方を説明し、別の訳し方と減点されやすい点も示します。
- 要約には、要点の押さえ方と組み立て方を付けています。

## 教材データ
- `data/books.js` — 各教材の章立てとページ。『誤用』続編1・続編2 は目次のページ番号どおり、基礎編は推定ページです。
- `data/idioms-*.js`、`data/translation-*.js`、`data/checkpoints.js`、`data/guide.js` — このアプリ用に書き下ろした問題・解説・学習法ガイド（参考文献つき）です。

## 検証
```bash
node tools/check-offline.js   # sw.js のキャッシュ一覧にアプリの全ファイルが入っているかを確認
node tools/check-plan.js   # 全範囲が試験日前に1回ずつ割り当てられているか、120分のタスクが重ならないかを確認
```

進捗はブラウザに保存されます。端末を替えるときは Settings の Export / Import を使ってください。
